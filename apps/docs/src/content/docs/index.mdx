## Project Overview

**Rotunde Music** is a modern monorepo for a music venue: a public website, Sanity CMS for content, and shared packages. It is built with Turborepo and uses pnpm workspaces.

### Architecture

- **Turborepo** — Task runner and caching for the monorepo
- **pnpm** — Package manager and workspaces
- **TypeScript** — Used across apps and packages

## Quick Start

### Prerequisites

- **Node.js** (v18+)
- **pnpm** — The repo uses `packageManager: "pnpm@10.28.0"`. Use corepack or install that version.

### Development

Run all apps in dev mode:

```bash
pnpm dev
```

From repo root:

```bash
pnpm build    # Build all
pnpm lint     # Lint all
pnpm format   # Format with Prettier
```

### Project Structure

```
rotunde-music/
├── apps/
│   ├── docs/          # This Starlight docs site
│   ├── studio/       # Sanity Studio (uses @repo/sanity)
│   └── web/          # Astro public site (React, UnoCSS, Vercel)
├── packages/
│   ├── constants/    # @repo/constants
│   ├── eslint-config/
│   ├── sanity/       # @repo/sanity — schema & plugins
│   ├── typescript-config/
│   └── ui/           # @repo/ui
└── turbo.json
```

## Key Technologies

- **Astro** — Docs site and public web app
- **Sanity CMS** — Headless CMS for venue/events/artists
- **React** — Used in Astro (web) and Sanity Studio
- **UnoCSS** — Styling in the web app
- **Turborepo** — Monorepo tasks and caching
