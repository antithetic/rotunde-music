## Project Configuration

The Sanity CMS is provided by the shared package **`@repo/sanity`**, used by the Studio app at `apps/studio/`.

### Project Details

- **Project ID**: `dm359cdv`
- **Dataset**: `production`
- **Studio Title**: Rotunde Music (from `@repo/constants` `SITE_NAME`)
- **Config name**: `rotunde`
- **Package**: `@repo/sanity`

### Architecture

- **Package**: `packages/sanity/`
- **Studio app**: `apps/studio/` re-exports the config: `export { default } from '@repo/sanity'`
- **Schema**: `packages/sanity/src/schema/` — `documents/`, `objects/`, `index.ts`
- **Utils**: `packages/sanity/src/utils/groups.ts` — field groups for Settings and Page

### Core Tools

- **Structure Tool** — Document list and navigation; includes **References** view per document
- **Vision Tool** — GROQ query runner

### Document Types

| Type       | Description |
|-----------|-------------|
| **Settings** | Singleton: venue info, address, hours, booking, SEO & social |
| **Artist**   | Name, description, photo, optional contact reference |
| **Contact**  | Name, phone, email, notes (referenced by Artist and others) |
| **Venue**    | Name, city |
| **Event**    | Name, slug, type (in-person/virtual), date, doors, venue ref, headline artist, image, details (blocks), tickets URL |
| **Page**     | Title, slug, content (blocks), SEO (meta, keywords, OG), author/tracking (userSelect, dates) |
| **Song**     | Title, artist, album, release year, slug, plus other fields |
| **Playlist** | Name, array of song references |
| **Newsletter** | Title |
